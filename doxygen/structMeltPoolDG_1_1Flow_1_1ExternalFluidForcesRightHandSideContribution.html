Detailed Description

template<int dim, typename number>
struct MeltPoolDG::Flow::ExternalFluidForcesRightHandSideContribution< dim, number >

An abstract interface for defining external forces acting on the fluid that must be evaluated and incorporated during the cell loop of an explicit time integration scheme.

This struct serves as a base for user-defined external fluid force models. Any derived class must implement the two core functions:

  • cell_operation(): Invoked once per cell batch to perform any necessary precomputations.
  • quad_operation(): Invoked at each quadrature point to compute the contribution of the external force.
