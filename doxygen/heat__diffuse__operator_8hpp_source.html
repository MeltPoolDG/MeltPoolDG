36 /*
37 * This operator computes the residual and its consistent tangent of the discretized heat
38 * equation with temperature dependent material properties:
39 * ρ^(n) = ρ(T^(n)), c_p^(n) = c_p(T^(n)), k^(n) = k(T^(n))
40 *
41 * 1 / \
42 * R(T_b^(n+1)) = --- | N_a, ρ^(n+1) c_p^(n+1) N_b ( T_b^(n+1) - T_b^(n)) ) |
43 * dt \ /
44 * Ω
45 * / \
46 * + | ∇N_a, k^(n+1) ∇N_b T_b^(n+1)) |
47 * \ /
48 * Ω
49 * / \
50 * + | N_a, ρ^(n+1) c_p^(n+1) ∇N_b T_b^(n+1) · u |
51 * \ /
52 * Ω
53 * / \
54 * + | N_a, ρ^(n+1) c_p^(n+1) N_b T_b^(n+1) ∇·u | (this term is not yet considered @todo)
55 * \ /
56 * Ω
57 * / _ \ / _ \
58 * - | N_a, q_s | - | N_a, q | = 0
59 * \ / \ /
60 * Ω Γ
61 * N
62 *
63 *
64 * dR(T^(n+1)) 1 / \
65 * ----------- = --- | N_a, ρ^(n+1) c_p^(n+1) N_b |
66 * dT_b^(n+1) dt \ /
67 * Ω
68 * 1 / d ρ c_p | \
69 * + -- | N_a, ---------| N_b ( T_b^(n+1) - T_b^(n)) ) |
70 * dt \ d T | /
71 * |(n+1) Ω
72 * / d k | \
73 * + | ∇N_a, k^(n+1) ∇N_b + -----| ∇N_b T_b^(n+1) |
74 * \ d T | /
75 * |(n+1) Ω
76 * / \
77 * + | N_a, ρ^(n+1) c_p^(n+1) ( ∇N_b u + N_b ∇·u ) |
78 * \ /
79 * Ω
80 * / d ρ c_p | \
81 * + | N_a, ---------| ( ∇N_b T_b^(n+1) · u + N_b T_b^(n+1) ∇·u ) |
82 * \ d T | /
83 * |(n+1) Ω
84 * _ _
85 * / d q_s \ / d q \
86 * - | N_a, --------- | - | N_a, --------- |
87 * \ dT_b^(n+1) / \ dT_b^(n+1) /
88 * Ω Γ
89 * N
90 *
91 * with shape functions N_a and N_b, nodal temperature values T_b^(n+1), the density ρ, the
92 * specific heat capacity c_p and the conductivity k, source/sink terms q_s and prescribed
93 * fluxes q along Neumann boundaries. The heat flux may result from radiative losses
94 *
95 * _
96 * q = σ ϵ (T^4-T∞^4)
97 *
98 * with the Stefan-Boltzmann constant σ, the emissivity ϵ and the temperature of the surroundings
99 * T∞ as well as convective losses
100 *
101 * _
102 * q = α (T-T∞)
103 *
104 * with the convection coefficient denoted as α.
105 *
106 * We assume that the density and the specific heat capacity do not dependent on the temperature.
107 *
108 */
