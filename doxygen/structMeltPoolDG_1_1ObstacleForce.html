Detailed Description

template<int dim, typename number, typename ObstacleType>
struct MeltPoolDG::ObstacleForce< dim, number, ObstacleType >

Interface class for forces acting on obstacles using type erasure.

This interface enables uniform handling of different force models by abstracting them through type erasure. Any force acting on the obstacles in an obstacle field must conform to this interface.

The only requirement for a class implementing a force model is to provide a member function named add_force_to_obstacles() that:

  • Takes a MeltPoolDG::ObstacleField as its argument. This object provides access to all necessary data describing the obstacles. Also the forces are added to the corresponing obstacles in this field.
