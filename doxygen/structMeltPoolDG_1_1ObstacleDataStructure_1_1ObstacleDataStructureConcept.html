Detailed Description

template<int dim, typename number>
struct MeltPoolDG::ObstacleDataStructure< dim, number >::ObstacleDataStructureConcept

Concept: Abstract interface for obstacle data structures.

Implementations must define how to reinitialize the structure, and how to extract obstacles from single cells or batches.See public interface for detailed function descriptions.
