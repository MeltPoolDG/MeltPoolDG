◆ save_state_to_restart_file()

template<int dim, typename number >
void MeltPoolDG::CfdDemApplication< dim, number >::save_state_to_restart_file ( )
private

Saves the current simulation state to a restart file.

This function performs a full checkpoint of the simulation, enabling it to be resumed later using load_state_from_restart_file().

The serialization process includes:

  • The internal state of this application (via Boost.Serialization of *this)
  • The triangulation, DoFHandler, and associated solution vectors (via deal.II's Restart and SolutionTransfer utilities)

Serializes the internal state of this class using the given archive.

This function handles the serialization of the internal data members necessary to reconstruct the class state, excluding the triangulation and solution vector(s).

Parameters
arThe archive used for serialization or deserialization.
versionThe serialization version (currently unused).
Note
The triangulation and associated solution fields are not serialized here. They are managed separately through deal.II's SolutionTransfer mechanism within the functions save_state_to_restart_file() and load_state_from_restart_file().

Sets up the amr indicator used to identify cells which need to be refined/coarsened.

Currently the indicator is an error estimator based on the combination of the jump and ssed estimator as discussed in the conference paper

F. Basile et al, A high-order h-adaptive discontinuous Galerkin method for unstructured grids based on a posteriori error estimation. https://arc.aiaa.org/doi/10.2514/6.2021-1696
