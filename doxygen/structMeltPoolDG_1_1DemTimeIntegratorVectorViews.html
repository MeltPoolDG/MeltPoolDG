Detailed Description

template<int dim, typename number, typename ObstacleType>
struct MeltPoolDG::DemTimeIntegratorVectorViews< dim, number, ObstacleType >

Holds required block vector views for DEM particle time integration.

This struct groups several ParticleHandlerBlockVectorView objects, each wrapped in a TimeIntegration::SolutionHistory to represent particle quantities such as position, velocity, and acceleration over time.

The views provide convenient non-owning access to particle data managed by a dealii::Particles::ParticleHandler, enabling vector-style operations without duplicating storage.
