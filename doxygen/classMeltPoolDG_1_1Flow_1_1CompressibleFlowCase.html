template<int dim>
void MeltPoolDG::Flow::CompressibleFlowCase< dim >::print_relative_norm ( const GenericDataOut< dim, double > &  generic_data_out,
dealii::Function< dim > &  reference_function,
const std::string &  norm_name = "Norm" 
) const
inlineprotected

This function calculates and prints the l2-norm of the solution given in generic_data_out compared to a reference state given by the function reference_function, i.e. it computes ||solution-reference||_2 for the primary variables density, momentum and energy density. The string norm_name is printed to the console to indicate what the calculated values represent.

Parameters
generic_data_outThe postprocessing data.
reference_functionAnalytical reference function for error/norm computation
norm_nameChoose between "Norm" and "Error"
