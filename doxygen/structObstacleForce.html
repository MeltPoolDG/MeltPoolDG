Detailed Description

template<int dim, typename number, typename ObstacleType>
struct ObstacleForce< dim, number, ObstacleType >

Interface class for forces acting on obstacles using type erasure.

This interface enables uniform handling of different force models by abstracting them through type erasure. Any force acting on an obstacle must conform to this interface.

The only requirement for a class implementing a force model is to provide a member function named compute_force_on_obstacle() that:

  • Takes a dealii::Particles::ParticleAccessor<dim> as its argument. This object provides access to all necessary data describing the obstacle.
  • Returns a dealii::Tensor<1, dim> representing the vectorial force acting on the obstacle.
