Detailed Description

Implementation of functions defined by C++23.

This file contains the implementation of different Riemann solvers for hyperbolic systems of conservation laws. The Riemann solvers are used to compute the numerical fluxes at the interfaces between cells in a finite volume or discontinuous Galerkin method.

Harten-Lax-van Leer (HLL) numerical flux, which approximates the Riemann problem at a face by two waves traveling with the smallest and the largest signal speed \(S^-\) and \(S^+\):

\[ \hat{F} = \frac{S^+ F(u^-) \cdot n - S^- F(u^+) \cdot n + S^- S^+ (u^+ - u^-)}{S^+ - S^-}. \]

Lax-Friedrichs numerical flux, computed using the maximum wave speed \(\lambda\) by

\[ \hat{F} = \frac{1}{2} \left(F(u^-) + F(u^+)\right) \cdot n + \frac{\lambda}{2} (u^- - u^+). \]
