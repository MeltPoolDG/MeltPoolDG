Compute and print the relative error norm for cut methods.

This function calculates and prints the l2-norm/l2-error of the solution given in generic_data_out compared to a reference state given by the function reference_function, i.e. it computes ||solution-reference||_2 for the primary variables density, momentum and energy density. The string norm_name is printed to the console to indicate what the calculated values represent. If the reference solution represents an exact analytical solution, the norm_name "error" should be chosen. Otherwise, the norm_name "norm" is appropriate for the l2-norm of the deviation to a certain defined reference state, e.g. initial conditions. It is necessary to provide a reference function for both cases.

Parameters
generic_data_outThe postprocessing data.
reference_functionAnalytical reference function for error/norm computation.
norm_nameChoose between "norm" and "error".

For cases which do not use cut methods, we can directly use the DoFHandler and DoFVector of the solution to compute error norms. This function computes and prints the relative error norm for fitted methods based on the register data post processor in the generic_data_out object. Only those relative errors given in the data vector are printed to the console.

Parameters
generic_data_outThe postprocessing data.
dataVector of names and reference functions for the components for which the error/norm should be computed and printed.
norm_nameName of the norm. Typically either "norm" or "error" depending on whether the reference function represents an exact solution or a certain reference state, e.g. initial conditions.
Exceptions
Ifa name given in the data vector does not have a corresponding registered data.
