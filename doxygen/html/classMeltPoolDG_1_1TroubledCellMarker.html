Detailed Description

template<int dim, int n_components, typename number>
class MeltPoolDG::TroubledCellMarker< dim, n_components, number >

Mark troubled cells, i.e., cells in which the candidate solution fails the physical admissibility check in at least one subcell, or violates the relaxed discrete maximum principle with respect to the old solution (see CellwiseNumericalAdmissibility).

const VectorType &  candidate,
const VectorType &  old_solution

Mark the troubled cells of candidate. The marked cells are stored internally and can be accessed with troubled_cells(). The candidate is considered admissible in a cell if it satisfies the physical admissibility check in all subcells and the numerical admissibility check with respect to the old solution (see CellwiseNumericalAdmissibility).

Parameters
matrix_free_contextMatrix-free data providing the dof and quadrature indices used to evaluate the solutions on the subcells.
candidateCandidate solution to be checked. Only its locally owned values are used.
old_solutionSolution from which the bounds of the numerical admissibility check are computed.

◆ numerically_admissible_cell_vector()

template<int dim, int n_components, typename number >
auto MeltPoolDG::TroubledCellMarker< dim, n_components, number >::numerically_admissible_cell_vector ( ) const

Returns a vector of bitsets, where active bits indicate that the solution on the cell is numerically admissible while non-active bits indicate that the solution on the cell is numerically inadmissible. The vector is indexed by the local batch index where each entry corresponds to a locally owned cell batch and each bit to a vectorization lane inside that cell batch.
