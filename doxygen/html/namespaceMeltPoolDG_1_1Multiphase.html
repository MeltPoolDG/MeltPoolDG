Detailed Description

Band solver for the ghost-penalty stabilized mass matrix of the cutDG compressible multiphase flow solver: the element mass matrices from all cells away from the interface are inverted exactly and only the through the ghost-penalty stabilization coupled band of cells around the interface is solved with a linear solver.

This operator solves the compressible two-phase Navier-Stokes equations, comprising the primary variables.

This file is only relevant temporarily and solves the level-set advection for one-dimensional test cases. When the incorporation of a full level-set velocity field is considered, the already available functionalities should be used.

Physics kernels for the interface terms of compressible two-phase flows.

Interface coupling methods for compressible two-phase flows.

The interface terms at a quadrature point on the unfitted phase interface are composed of two independent parts:

  • the convective coupling (HLLP0ConvectiveCoupling),
  • the viscous coupling, which depends on the selected InterfaceNumericalMethod (SIPGViscousCoupling, PenaltyViscousCoupling, or InviscidCoupling for inviscid phases),

The relevant jump conditions (evaporation mass flux, temperature jump, laser heat source) are modeled in the InterfaceJumpModel class.

The physics kernels of the interface terms live in multiphase_interface_kernels.hpp.

All couplings write their contributions into an InterfaceFlux with the following sign convention: the stored terms are exactly the terms that are submitted to the evaluators.

The viscous coupling is selected once from the input parameters by create_viscous_interface_coupling() and stored in the std::variant ViscousCoupling.

Two different strategies for enforcing the interface jump conditions are implemented:

  • "HLLP0 and SIPG": approximate HLLP0 Riemann solver for convective fluxes and Nitsche-type method for viscous fluxes, consistently aligned to the SIPG method for inner faces
  • "HLLP0 and penalty": approximate HLLP0 Riemann solver for convective fluxes and a combination of strong incorporation in the weak form and penalty terms for the viscous fluxes

The composed interface constraint methods ("HLLP0 and SIPG", "HLLP0 and penalty") are assembled from these kernels in multiphase_interface_coupling.hpp.

Calculate the convective flux with the HLLP0 Riemann solver.

This function calculates the convective fluxes for both phases at the phase interface and the interface normal speed at the considered quadrature point. The HLLP0 approximate Riemannn solver for phase transition is implemented according to the following paper: Joens, Munz, 2023: 'Riemann solvers for phase transition in a compressible sharp-interface method.'

Parameters
liquid_stateState view for liquid phase at quadrature point on the (unfitted) interface.
gas_stateState view for gas phase at quadrature point on the (unfitted) interface.
normalInterface normal vector, pointing outside the liquid phase.
convective_kernel_liquidObject with reference to the material data needed for convective flux calculations in the liquid phase.
convective_kernel_gasObject with reference to the material data needed for convective flux calculations in the gas phase.
m_dot_evapCurrent evaporation mass flux (SI: in kg/(m^2 s)).
Returns
Tuple, containing the convective fluxes for liquid and gas phase, respectively, and the interface normal velocity.
Note
The HLLP0 solver can be solved explicitly, no iterative solution strategy is required. The solver is also applicable for vanishing evaporation mass flux (reduces to the HLLC solver).

Calculates the viscous flux at the phase interface with a combined direct and penalty approach.

The viscous interface flux is incorporated directly in the weak form in combination with penalty terms for the temperature jump and, for dim > 1, the tangential no-slip constraint.
