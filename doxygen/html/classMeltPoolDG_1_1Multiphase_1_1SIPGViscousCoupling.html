Detailed Description

template<int dim, typename number>
class MeltPoolDG::Multiphase::SIPGViscousCoupling< dim, number >

Viscous interface coupling of the method "HLLP0 and SIPG".

SIPG method for the viscous fluxes, consistently aligned to the SIPG method for inner faces, as described in: Henneaux, 2023: 'Higher-order enforcement of jumps conditions between compressible viscous phases: An extended interior penalty discontinuous Galerkin method for sharp interface simulation.'
