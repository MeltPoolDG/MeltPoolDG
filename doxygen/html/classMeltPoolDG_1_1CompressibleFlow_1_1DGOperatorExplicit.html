number  time_step,

const VectorType &  previous_solution,
const dealii::AlignedVector< dealii::VectorizedArray< number > > &  troubled_cells 
) const

Apply the finite volume subcell limiter to the candidate solution of a forward Euler step.

In the troubled cells, the candidate solution is replaced by a forward Euler step of the finite volume subcell scheme starting from previous_solution. The finite volume right-hand side contains the convective fluxes and the external forces. Viscous terms are not considered yet.

In the untroubled neighbors of troubled cells, the update is corrected such that it uses the finite volume flux instead of the DG flux at the faces shared with troubled cells. Thus, both cells use the same flux at their common faces and the scheme remains conservative. In all other cells, the candidate solution is not changed.

The correction of the untroubled neighbors assumes that candidate_solution is the result of a DG forward Euler step from previous_solution with the same time_step. Therefore, the limiter is only available for strong stability preserving Runge-Kutta schemes, where each stage is such a step, and an exception is thrown for other time integrators.

Parameters
timeThe current time.
time_stepThe time step size of the forward Euler step.
candidate_solutionOn input, the solution of the DG forward Euler step. On output, the limited solution.
previous_solutionThe solution from which the forward Euler step starts.
troubled_cellsTroubled cell markers, read per cell batch via read_cell_data(), where a nonzero entry in a lane marks the corresponding cell as troubled. The markers must also be set for the ghost cell batches, since the face loops need to know whether the neighbor across a face is troubled.

Computes the value of the function f(y) for the compressible Navier-Stokes equations of the form y' = f(y).

From a discretization perspective, f(y) is given by f(y) = M^(-1) * F(y), where M is the mass matrix and F(y) is the sum of all flux contributions: F_v + F_c + F_rhs.

Parameters
timeThe current time at which the function is evaluated.
dstVector where the computed value of f(y) is stored.
srcThe solution vector, y, at the current time.
funcA function to be executed after f(y) has been computed. This function is applied to the resulting vector in dst.

Local face applier for the conservation correction of the finite volume subcell limiter.

At a face between a troubled and an untroubled cell, the troubled cell is updated with the finite volume flux, while the DG update of the untroubled cell contains the DG flux. For the untroubled cell, this function computes the face integral of the difference between the two fluxes, which replaces the DG flux by the finite volume flux once the inverse mass matrix is applied.

Parameters
matrix_freeMatrix free object on which the applier works on.
dstDestination vector to which the face integrals are added.
old_solutionSolution at the beginning of the time step.
face_rangeFace range which is considered in the applier.
troubled_cellsCell data vector marking the troubled cells, including the ghost cell batches.
