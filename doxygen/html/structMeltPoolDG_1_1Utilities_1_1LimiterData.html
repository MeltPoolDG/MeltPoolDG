Detailed Description

An enumeration of the available limiters.

  • none: No limiter is applied
  • slope_limiter: Slope limiter applied to all cells
  • fv_subcell: Finite volume subcell limiter An enumeration of the available limiter functions $\phi(r)$, see limiter_functions.hpp for their definitions.
  • tvd_minmod: Minmod limiter function
  • superbee: Superbee limiter function of Roe
  • muscl: Monotonized central limiter function of van Leer
  • harmonic: Van Leer limiter function (harmonic mean of the slopes) An enumeration for the available troubled cell marking strategies. The following strategies are available:
  • subcell_pad: Mark a cell as troubled if any of its subcell values are outside the physical admissible range.
  • cell_nad: Mark a cell as troubled if the discrete maximum principle is violated on the cell level, i.e. if any of the cell values exceed the extrema of the old solution on the solution and the face neighbors of the cell. See CellwiseNumericalAdmissibility for details.
  • subcell_nad: Mark a cell as troubled if the discrete maximum principle is violated on the subcell level, i.e. if any of the subcell values are outside the extrema of the old solution over the subcell itself and its face neighbors. See SubcellNumericalAdmissibility for details. A struct to hold the data for the limiters.
