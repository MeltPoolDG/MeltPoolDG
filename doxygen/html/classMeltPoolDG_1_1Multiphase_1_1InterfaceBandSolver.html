Detailed Description

template<typename number, typename VectorType>
class MeltPoolDG::Multiphase::InterfaceBandSolver< number, VectorType >

Specialized solver for the linear system of the cutDG compressible multiphase flow solver, i.e., the cutDG mass matrix with face-based ghost-penalty stabilization.

The solver

  1. applies the exact inverse of the cell mass matrices to the cells away from the interface,
  2. solves the remaining (small) band system with a linear solver.

The band system is formulated on compressed vectors, which only contain the band DoFs (with a contiguous global numbering of the band DoFs). The operator of the band system copies the entries of a compressed vector into the band entries of a vector with the layout of the full system, applies the system matrix restricted to the band and copies the band entries of the result back. The system matrix restricted to the band is only evaluated on the cell batches containing band cells and on the ghost-penalty faces, which all lie within the band. Thus, the vector operations of the linear solver only touch the band.

Note
The cost of the band solve scales with the number of cells in the band, i.e., with the size of the interface, and not with the total number of cells.
