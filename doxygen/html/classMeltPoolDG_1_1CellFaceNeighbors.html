Detailed Description

template<int dim>
class MeltPoolDG::CellFaceNeighbors< dim >

A class that caches the matrix free cell batch index and lane index of the neighbors of each cell face. Once set up, it allows for efficient access to the neighbor information without repeated queries to the matrix free object.

template<int dim>
template<typename number >
void MeltPoolDG::CellFaceNeighbors< dim >::reinit ( const dealii::MatrixFree< dim, number > &  matrix_free)
inline

This function initializes the neighbor information for each cell face. It stores the neighbor indices of each cell internally. After a call to this function, the neighbor information can be accessed using the operator() function.

Note
This function requires that the values of all ghost cells are locally available. This can be achieved by setting MatrixFree::AdditionalData::hold_all_faces_to_owned_cells = true and enabling face integrals.
This function must be called every time the matrix free object is reinitialized, as the cell batches and lanes may change.
