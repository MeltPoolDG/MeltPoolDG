Detailed Description

template<int dim, typename number>
class MeltPoolDG::PostProcessingTools::LevelSetMeasuresCalculator< dim, number >

Compute the measures of the two phases and of the interface described by the zero isosurface of a discrete level-set field ϕ, i.e.

|Ω⁺| = ∫ dΩ , |Ω⁻| = ∫ dΩ , |Γ| = ∫ dΓ Ω⁺ Ω⁻ Γ

with Ω⁺ = {ϕ > 0}, Ω⁻ = {ϕ < 0} and Γ = {ϕ = 0}. In 2D, the phase measures are areas and the interface measure is a length; in 3D, they are volumes and a surface area, respectively.

The quadrature rules for the subdomains and the interface are generated by dealii::NonMatching::DiscreteQuadratureGenerator, which is based on the algorithm of Saye (2015), "High-order quadrature methods for implicitly defined surfaces and volumes in hyperrectangles". Cells not intersected by the interface are integrated with a standard Gauss quadrature. The mapping attached to the GenericDataOut object is considered.

For elements derived from FE_Q_Base (e.g. FE_Q, FE_Q_iso_Q1), the cells are classified by dealii::NonMatching::MeshClassifier. In particular, if the zero level set coincides with a cell face, only the cell on the side of negative level-set values is classified as intersected, so that the interface is not counted twice. For other elements (e.g. FE_DGQ), which are not supported by the MeshClassifier, a cell is considered intersected if the quadrature generator returns a non-empty quadrature for the negative phase and a non-empty quadrature for the positive phase or the interface. This yields the same treatment of interfaces coinciding with cell faces.

Note
The level-set field has to be described by a scalar element (e.g. FE_Q, FE_Q_iso_Q1 or FE_DGQ) on hypercube cells and a DoFHandler without hp-capabilities.
