Detailed Description

template<int dim, int n_components, typename number>
class MeltPoolDG::CellwiseNumericalAdmissibility< dim, n_components, number >

Numerical admissibility detection with cellwise bounds, based on the relaxed discrete maximum principle used by Vilar [1] to detect spurious oscillations across cells of a DG candidate solution.

The candidate \(u^{n+1}\) is admissible in cell \(i\) if all of its subcell values lie within the extrema of the subcell values of the old solution \(u^n\) over the cell itself and its face neighbors, relaxed by a small tolerance:

\[ m_i - \delta_i \leq u{i,s}^{n+1} \leq M_i + \delta_i \quad \text{for all subcells } s \text{ of cell } i, \]

with

\[ m_i = \min_{j \in \{i\} \cup \mathcal{N}(i)} \min_{s} u_{j,s}^n, \qquad M_i = \max_{j \in \{i\} \cup \mathcal{N}(i)} \max_{s} u_{j,s}^n, \qquad \delta_i = \max\left(\delta_0, \varepsilon \left(M_i - m_i\right)\right), \]

where \(\mathcal{N}(i)\) is the set of face neighbors of cell \(i\) and \(u_{j,s}\) is the value on subcell \(s\) of cell \(j\) as given by FESubcellEvaluation. Cells sharing only an edge or a vertex with cell \(i\) do not contribute. The check is applied to each component separately, and a cell is admissible only if all components pass.

Usage

Call reinit() every time the MatrixFree object is reinitialized. Each evaluation then consists of three steps:

  1. Call submit_cell() for every locally owned cell batch, with the old solution and the candidate evaluated on that batch,
  2. Call submit_ghost_cell() for every ghost cell batch, with the old solution evaluated on that batch,
  3. evaluate(), which sets the bits of the admissible lanes of every locally owned cell batch.
Note
In parallel, all face neighbors of the locally owned cells must be available as ghost cells of the MatrixFree object. This requires MatrixFree::AdditionalData::hold_all_faces_to_owned_cells = true and enabled face integrals, since by default MatrixFree only stores the ghost cells behind the faces it processes locally.

[1] F. Vilar, A posteriori correction of high-order discontinuous Galerkin scheme through subcell finite volume formulation and flux reconstruction, J. Comput. Phys. 387, 2019.

◆ evaluate()

template<int dim, int n_components, typename number >
void MeltPoolDG::CellwiseNumericalAdmissibility< dim, n_components, number >::evaluate ( std::vector< std::bitset< VectorizedArrayType::size()> > &  masks)

Take the submitted old and candidate values for all locally owned and ghost cell batches and compute the admissibility of the candidate solution for each locally owned cell batch. The admissibility is determined by checking if the candidate values lie within the extrema of the old values over the cell and its face neighbors, relaxed by a small tolerance.

Parameters
masksA vector of bitsets, where each bitset corresponds to a locally owned cell batch and each bit corresponds to a vectorization lane. The bits are set to 1 for admissible lanes and 0 for inadmissible lanes. It is assumed that the given vector already has the correct size.

Same as submit_cell(), but for ghost cell batches. The candidate solution is not needed for ghost cells, since the admissibility check is only performed for locally owned cells. However locally owned cells at MPI process boundaries require the old solution on the ghost cells to compute the extrema over the cell and its face neighbors.

Parameters
ghost_cell_batchThe index of the ghost cell batch for which the old values are submitted.
phi_oldThe FESubcellEvaluation object containing the old solution evaluated on the ghost cell batch.
