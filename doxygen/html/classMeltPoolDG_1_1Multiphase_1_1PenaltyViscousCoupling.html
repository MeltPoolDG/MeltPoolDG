Detailed Description

template<int dim, typename number>
class MeltPoolDG::Multiphase::PenaltyViscousCoupling< dim, number >

Viscous interface coupling of the method "HLLP0 and penalty".

The viscous interface flux is incorporated directly in the weak form in combination with penalty terms for the temperature jump and for the tangential no-slip constraint.
