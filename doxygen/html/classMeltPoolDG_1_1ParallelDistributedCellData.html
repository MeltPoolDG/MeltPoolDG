Detailed Description

template<int dim, typename number, typename VectorizedArrayType = dealii::VectorizedArray<number>>
class MeltPoolDG::ParallelDistributedCellData< dim, number, VectorizedArrayType >

This class provides a parallel distributed cell data vector primarily intended to be used with dealii::FEEvaluation and dealii::FEFaceEvaluation. In contrast to a plain AlignedVector initialized with dealii::MatrixFree::initialize_cell_data_vector(), this class allows for conveniently updating the ghost values, i.e., the cell data of the ghost cell batches. This can be useful if you need the cell data locally available for both locally owned and ghost cells, but the data itself can only be computed for the locally owned cells. The ghost values can then be updated by calling update_ghost_values(), which sends the values of the locally owned cells to the neighboring MPI processes.

void MeltPoolDG::ParallelDistributedCellData< dim, number, VectorizedArrayType >::reinit ( const dealii::MatrixFree< dim, number, VectorizedArrayType > &  matrix_free)
inline

Initializes the cell data vector. It sets the size of the vector according to the number of locally owned and ghost cell batches in the matrix free object. It also sets up the communication pattern used internally to exchange the ghost values of the cell data vector with neighboring MPI processes. This function must be called every time the matrix free object is reinitialized.

Parameters
matrix_freeThe matrix free object used to determine the number of cell batches and the communication pattern for exchanging ghost values.

◆ update_ghost_values()

template<int dim, typename number , typename VectorizedArrayType = dealii::VectorizedArray<number>>
void MeltPoolDG::ParallelDistributedCellData< dim, number, VectorizedArrayType >::update_ghost_values ( )
inline

Updates the ghost values of the cell data vector by sending the values of the locally owned cells to the neighboring MPI processes. After a call to this function, the values of the ghost cell batches are up-to-date and can be used for computations that require ghost cell information, e.g., reading the cell data of the exterior cell of a face at an MPI process boundary with FEFaceEvaluation::read_cell_data().
