Detailed Description

template<int dim, typename number>
class MeltPoolDG::ParticleHandlerVectorView< dim, number >

A vector-like view into a specific property of all particles managed by a dealii::Particles::ParticleHandler.

This class provides a lightweight interface that mimics the most important features of a deal.II distributed vector, but without owning any memory. Instead, it offers direct access to a selected property (or coordinate component) of each particle managed by the associated ParticleHandler. Conceptually, it exposes that property as if all values were stored in a single, contiguous vector.

The main purpose of this class is to enable vector-style operations (such as scaling, addition, or subtraction) directly on particle properties while maintaining compatibility with common deal.II vector interfaces.

Note
The particle properties are not stored contiguously in memory. Each particle stores all of its properties consecutively, and the next particle’s properties follow. Consequently, accessing a specific property across all particles involves a strided memory access pattern.

Constructor. Initializes the vector view for a specific property of the particles, i.e., sets all required references.

Parameters
particle_handlerThe particle handler that provides access to the actual particle data.
property_indexIndex of the property in the particle property array that this vector view should access. If index_describes_location is true, this corresponds to the coordinate component (e.g., x/y/z) and must be less than dim. In this case it is assumed that the given index corresponds to the spatial direction.
index_describes_locationFlag indicating whether property_index refers to a particle location component (true) or a generic property (false).

Updates ghost particle values.

Synchronizes ghost particles across MPI ranks. If exchange_particles is true, particles are also exchanged between ranks as needed, potentially changing ownership. In all cases, the properties of ghost particles are updated.

Parameters
exchange_particlesWhether to exchange ghost particles (true) or only update their properties (false).
