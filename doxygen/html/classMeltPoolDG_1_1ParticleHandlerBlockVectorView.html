Detailed Description

template<int dim, typename number>
class MeltPoolDG::ParticleHandlerBlockVectorView< dim, number >

A block vector view providing access to multiple particle properties managed by a dealii::Particles::ParticleHandler.

This class acts as a lightweight, non-owning container of several ParticleHandlerVectorView objects, each representing a specific particle property or coordinate component. Together, they form a block-structured vector interface similar to deal.II’s BlockVector classes.

The block vector view provides a subset of the deal.II block vector interface (e.g., access to blocks, scaling, and addition operations), allowing users to work with multiple particle properties in a unified way while maintaining consistency with deal.II’s vector abstractions.

Note
Like ParticleHandlerVectorView, this class provides only a view into existing particle data and does not own or allocate any memory. The underlying particle properties are stored in a strided memory layout.
