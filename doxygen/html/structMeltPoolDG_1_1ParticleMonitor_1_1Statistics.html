Detailed Description

template<int dim, typename number, typename ObstacleType>
struct MeltPoolDG::ParticleMonitor< dim, number, ObstacleType >::Statistics

A helper struct that represents the statistics of a single unsigned integer quantity over all recorded samples.

◆ add_info_with_imbalance()

template<int dim, typename number , typename ObstacleType >
void MeltPoolDG::ParticleMonitor< dim, number, ObstacleType >::Statistics::add_info_with_imbalance ( const unsigned int  value,
MPI_Comm  mpi_communicator 
)

Records one sample of the quantity and the load imbalance of this sample across all MPI ranks. The load imbalance is defined as the maximum of value over all MPI ranks divided by its mean, i.e., a value of 1 means perfectly balanced.

Parameters
valueThe value of the sample on the current MPI rank.
mpi_communicatorMPI communicator over which the load imbalance is computed.
Note
This is a collective operation and must be called on all MPI ranks in the MPI communicator.
