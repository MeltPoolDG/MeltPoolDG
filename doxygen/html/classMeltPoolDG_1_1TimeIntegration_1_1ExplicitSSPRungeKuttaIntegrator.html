Perform the actual time integration for a single time step using the strong-stability preserving explicit Runge-Kutta scheme.

Parameters
current_timeCurrent time.
time_stepCurrent time step size.
solution_historySolution history object providing the current and all required previous solutions.
stage_pre_processingFunction executed at the beginning of each stage. It receives the time at which the rhs will be evaluated, the size of the forward Euler step of the stage, the vector which will hold the forward Euler step, and the solution the step starts from.
stage_post_processingFunction executed after the forward Euler step of each stage, before it is combined with the solution at the beginning of the time step. It receives the time at which the most recent rhs was evaluated, the time step size of the recent Euler step, the vector holding the forward Euler step result, and the solution the step started from.

template<typename number >
std::vector<number> MeltPoolDG::TimeIntegration::ExplicitSSPRungeKuttaIntegrator< number >::old_solution_weights
private

Coefficients of the scheme in Shu-Osher form: stage i computes u^(i) = old_solution_weights[i] * u^n + stage_solution_weights[i] * u^(i-1)

  • time_step_weights[i] * dt * F(u^(i-1), rhs_time_weights[i] * dt), with u^(0) = u^n and u^{n+1} = u^(n_stages).
