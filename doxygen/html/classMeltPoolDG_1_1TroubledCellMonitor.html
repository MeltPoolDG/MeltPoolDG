Detailed Description

template<int dim, int n_components, typename number>
class MeltPoolDG::TroubledCellMonitor< dim, n_components, number >

This class monitors the troubled cells marked by a TroubledCellMarker over time and allows to print statistics about them if requested.

Each call to add_info() records one sample, i.e., the cells marked in the last call to TroubledCellMarker::mark() of the monitored marker. The counts are summed over all MPI ranks when the sample is recorded, such that the statistics refer to the global number of cells. The printed table contains the number of samples, the average, the minimum and the maximum of

  • the number of troubled cells,
  • the number of cells marked by the physical admissibility detection (PAD),
  • the number of cells marked by the numerical admissibility detection (NAD),
  • the number of cells marked by both PAD and NAD. Quantities of marking strategies which are not applied are omitted.

Samples are only recorded after the monitor has been subscribed to a ProfilingMonitor, whose verbosity determines which statistics are recorded.

template<int dim, int n_components, typename number >
void MeltPoolDG::TroubledCellMonitor< dim, n_components, number >::add_info ( const MatrixFreeContext< dim, number > &  matrix_free_context)

Records one sample of the troubled cell statistics, i.e., counts the cells marked in the last call to TroubledCellMarker::mark() of the monitored marker. Does nothing if the monitor has not been subscribed to a profiling monitor or its verbosity is ProfilingVerbosity::none.

Parameters
matrix_free_contextMatrix-free context with which the marker has been called.
Note
This is a collective operation and must be called on all MPI ranks.
