template<int dim, int n_components, typename number , typename VectorizedArrayType = dealii::VectorizedArray<number>, typename VectorType = dealii::LinearAlgebra::distributed::Vector<number>>
void MeltPoolDG::Utilities::apply_slope_limiter ( const MatrixFreeContext< dim, number > &  mf_context,
VectorType &  dst,
const VectorType &  src,
const LimiterData &  limiter_data 
)

This function applies the slope limiter to the solution vector in a cell-wise manner using the provided matrix-free context. It basically iterates over each cell to compute the limited solution based on the specified limiter function in the limiter data struct. Nothing is done if the limiter type is not LimiterType::slope_limiter. For more details see Cockburn and Shu, "The Runge-Kutta Discontinuous Galerkin Method for Conservation Laws V: Multidimensional Systems", Journal of Computational Physics, 141(2):199–224, 1998.

Parameters
mf_contextContext containing a reference to the matrix-free object and relevant indices for dofs and quadrature.
dstThe destination vector where the limited solution will be stored.
srcThe source vector containing the current solution values to be limited.
limiter_dataStruct containing the limiter type and relevant parameters for the limiter.

template<int dim, int n_components, typename number >
std::array< dealii::Tensor< 1, n_components, number >, dim > MeltPoolDG::Utilities::compute_limited_slopes ( const std::vector< std::pair< dealii::Tensor< 1, n_components, number >, dealii::Tensor< 1, n_components, dealii::Tensor< 1, dim, number > > > > &  cell_average_values,
const typename dealii::Triangulation< dim >::active_cell_iterator &  cell,
const LimiterData &  limiter_data 
)

This function computes the limited slopes for a given cell. It computes the finite difference slopes with respect to the cell averages of the current cell and its neighbors in all directions separately and combines them with the minmod limiter function into a single difference slope. The average cell gradient is then limited against this difference slope with the limiter function specified by limiter_data.limiter_function_type. The resulting limited slopes are returned as an array of tensors, where each tensor corresponds to a spatial direction.

Parameters
cell_average_valuesA vector containing the cell average values for all cells in the domain.
cellThe active cell iterator for the current cell for which the limited slopes are being computed.
limiter_dataStruct containing the limiter type and relevant parameters for the limiter.
Returns
An array of tensors containing the limited slopes for each spatial direction.

◆ compute_slope_ratio()

template<int n_components, typename number >
dealii::Tensor< 1, n_components, number > MeltPoolDG::Utilities::compute_slope_ratio ( const dealii::Tensor< 1, n_components, number > &  numerator,
const dealii::Tensor< 1, n_components, number > &  denominator 
)

Computes the component-wise ratio $r = a / b$ of two slopes $a$ (numerator) and $b$ (denominator), which is the input of the limiter functions $\phi(r)$ below. The limited slope is then given by $b \, \phi(r)$. In the classical slope limiting setting, $a$ and $b$ are the forward and backward difference slopes $u_{x,i+1/2}$ and $u_{x,i-1/2}$.

For a vanishing denominator, the ratio is set to zero. Since all limiter functions are bounded, the limited slope $b \, \phi(r)$ is zero in this case independent of the value of $r$.

Note
The number type may also be a dealii::VectorizedArray.
Parameters
numeratorThe slope $a$ in the numerator of the ratio.
denominatorThe slope $b$ in the denominator of the ratio.
Returns
The component-wise ratio $r = a / b$.

◆ tvd_minmod()

template<int n_components, typename number >
dealii::Tensor< 1, n_components, number > MeltPoolDG::Utilities::tvd_minmod ( const dealii::Tensor< 1, n_components, number > &  r)

Evaluates the minmod limiter function

\[ \phi(r) = \max(0, \min(1, r)) \]

component-wise for the ratio $r = a / b$ of two slopes, see compute_slope_ratio(). The limited slope $b \, \phi(r)$ equals $\operatorname{minmod}(a, b)$, i.e.

  • the slope with the smaller magnitude if both slopes share the same sign, and
  • zero if the signs differ (indicating a local extremum), to damp oscillations.
Note
The number type may also be a dealii::VectorizedArray.
Parameters
rThe component-wise ratio of two slopes.
Returns
The component-wise values of the limiter function.
