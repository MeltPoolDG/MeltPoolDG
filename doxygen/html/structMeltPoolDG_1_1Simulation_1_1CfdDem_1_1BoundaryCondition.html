Detailed Description

template<int dim, typename number>
struct MeltPoolDG::Simulation::CfdDem::BoundaryCondition< dim, number >

Struct for storing boundary condition information for a specific boundary and creating a corresponding function object for use in simulations.

template<int dim, typename number >
std::shared_ptr< dealii::Function< dim > > MeltPoolDG::Simulation::CfdDem::BoundaryCondition< dim, number >::create_boundary_function ( const number  start_time)
inline

Creates a function object representing the boundary condition based on the data stored in this struct. For example, for a fixed-pressure outflow, this returns a dealii::Function representing the pressure field at the boundary.

Parameters
