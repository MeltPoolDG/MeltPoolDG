Perform the actual time integration for a single time step using the explicit Runge-Kutta Chebyshev scheme.

Parameters
current_timeCurrent time.
time_stepCurrent time step size.
solution_historySolution history object providing the current and all required previous solutions.
stage_pre_processingFunction which is executed at the beginning of each Runge-Kutta Chebyshev stage. Four variables are passed to the function: the current time, the current time step, the vector which is later used in the stage computation and the current stage solution.
stage_post_processingFunction which is executed at the end of each Runge-Kutta Chebyshev stage. Four variables are passed to the function: the current time after perfoming the stage, the current time step, the vector which is later used in the subsequent computations, and the solution of the Runge-Kutta Chebyshev stage.
