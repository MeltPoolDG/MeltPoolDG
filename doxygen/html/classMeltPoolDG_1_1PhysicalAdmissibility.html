Detailed Description

template<int dim, int n_components, typename number>
class MeltPoolDG::PhysicalAdmissibility< dim, n_components, number >

Physical admissibility detection: the candidate solution is physically admissible in a cell if it is physically admissible in all subcells of the cell. Whether a subcell state is physically admissible is decided by a user-provided function, e.g., by checking for positive density and pressure in a compressible flow.

The usage is similar to CellwiseNumericalAdmissibility: call reinit() every time the MatrixFree object is reinitialized, submit_cell() for every locally owned cell batch, and then evaluate(). Since each cell is checked on its own, no ghost cells are required.

Returns a vector of bitsets, where each bitset corresponds to a locally owned cell batch and each bit to a vectorization lane. The bits of the physically admissible lanes are set, while the bits of the physically inadmissible lanes are unset.

◆ evaluate()

template<int dim, int n_components, typename number >
void MeltPoolDG::PhysicalAdmissibility< dim, n_components, number >::evaluate ( std::vector< MaskType > &  troubled_cells_mask)

Mark the lanes of each locally owned cell batch in which the candidate is physically inadmissible in at least one subcell.

Parameters
troubled_cells_maskA vector of bitsets, where each bitset corresponds to a locally owned cell batch and each bit to a vectorization lane. The bits of the physically inadmissible lanes are set, while all other bits are kept, i.e., the result is combined with the existing bits by a logical OR. It is assumed that the given vector already has the correct size.
