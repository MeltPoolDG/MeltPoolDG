Evaluate the boundary value function in the given vectorization lanes and write the results into the corresponding lanes of boundary_value_dst. Since the lanes may lie on boundaries with different ids, the function is called once per distinct boundary id among the lanes in lanes, and its result is only copied into the lanes on a boundary with this id. The lanes not contained in lanes are left unchanged.

Parameters
lanesThe vectorization lanes that lie on the domain boundary.
boundary_idsThe boundary id of each lane. Only the entries of the lanes in lanes are accessed.
boundary_pointThe location on the boundary face passed to boundary_value_function.
normal_vectorThe outward unit normal vector of the boundary face passed to boundary_value_function.
valueThe value of the subcell adjacent to the boundary passed to boundary_value_function.
boundary_value_dstThe value into whose lanes the boundary values are written.
boundary_value_functionThe function returning the value on the boundary face, called as boundary_value_function(boundary_point, normal_vector, boundary_id, value).
