Detailed Description

template<int dim, ArithmeticType ValueType, typename Derived>
struct MeltPoolDG::CompressibleFlow::DofPrimitiveValueMixin< dim, ValueType, Derived >

CRTP mixin providing semantic access to primitive variables.

This mixin assumes that the derived class exposes:

auto value();

returning a tensor-like container indexed according to TensorStorageIndex<dim>.

It provides direct access to primitive variables (pressure, velocity, temperature).

All accessors are thin inline wrappers around the underlying storage. No additional data members are introduced and no quantities are cached.

Template Parameters
ValueTypeType of a single value in the underlying storage container obtained when using [] on value() of the derived class.
