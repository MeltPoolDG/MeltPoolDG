Detailed Description

template<int dim, int n_components, typename number>
struct MeltPoolDG::TroubledCellMonitor< dim, n_components, number >::Statistics

A helper struct that represents the statistics of the global number of cells marked by one strategy over all recorded samples.

template<int dim, int n_components, typename number >
void MeltPoolDG::TroubledCellMonitor< dim, n_components, number >::Statistics::add_imbalance ( const number  imbalance)

Records the load imbalance of one sample across all MPI ranks, defined as the maximum of the locally owned value over all MPI ranks divided by its mean, i.e., a value of 1 means perfectly balanced.
