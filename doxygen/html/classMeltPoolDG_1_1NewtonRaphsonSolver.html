Detailed Description

template<typename number, typename VectorType = dealii::LinearAlgebra::distributed::Vector<number>>
class MeltPoolDG::NewtonRaphsonSolver< number, VectorType >

Newton-Raphson solver for a nonlinear system of equations \(F(x) = 0\).

The solver does not know the nonlinear problem itself. Instead, the problem is defined by the public std::function members residual, solve_with_jacobian, reinit_vector, distribute_constraints and norm_of_solution_vector, which have to be set before calling solve().

Algorithm

Starting from the initial guess \(x_0\) passed to solve(), each Newton iteration \(k\)

  1. computes the right-hand side \(r_k = -F(x_k)\) with residual(),
  2. solves the linearized system \(J(x_k)\,\Delta x_k = r_k\) with solve_with_jacobian(), where \(J = \partial F / \partial x\) is the Jacobian,
  3. checks for convergence, and, if not converged,
  4. updates the solution \(x_{k+1} = x_k + \Delta x_k\) and applies the constraints with distribute_constraints().

Convergence criterion

The solver is converged if both the residual and the solution update are small, i.e.

\[ \|r_k\| < \mathrm{tol}_r \quad \mathrm{and} \quad \|\Delta x_k\| < \mathrm{tol}_{\Delta x}, \]

with the l2 norms of the vectors and the tolerances NonlinearSolverData::residual_tolerance and NonlinearSolverData::field_correction_tolerance.

If NonlinearSolverData::use_relative_tolerances is set, the tolerances are interpreted relative to reference norms:

\[ \frac{\|r_k\|}{\|r_0\|} < \mathrm{tol}_r \quad \mathrm{and} \quad \frac{\|\Delta x_k\|}{\|x_k\|} < \mathrm{tol}_{\Delta x}, \]

where \(r_0\) is the right-hand side of the first Newton iteration of the current call to solve() and \(x_k\) the current iterate. If a reference norm is zero, the respective tolerance is applied as an absolute value.

If the solver does not converge within NonlinearSolverData::max_nonlinear_iterations iterations, it continues for up to NonlinearSolverData::max_nonlinear_iterations_alt iterations with the alternative tolerances NonlinearSolverData::residual_tolerance_alt and NonlinearSolverData::field_correction_tolerance_alt. If it does not converge with those either, ExcNewtonDidNotConverge is thrown. Each call to solve() starts with the standard tolerances.

Note
If a linear solver with an absolute tolerance is used in solve_with_jacobian(), this tolerance limits how far the residual can be reduced: once \(\|r_k\|\) falls below it, the linear solver returns a zero update. In combination with relative tolerances, make sure that the absolute tolerance of the linear solver is well below \(\mathrm{tol}_r \|r_0\|\).

Output

For NonlinearSolverData::verbosity_level >= 2, the number of linear iterations and the norms compared against the tolerances are printed in each Newton iteration. For NonlinearSolverData::verbosity_level >= 1, the norm of the converged solution is printed.
