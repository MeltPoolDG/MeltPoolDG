Detailed Description

template<int dim, typename number>
struct MeltPoolDG::ObstacleDataStructure< dim, number >

Interface class for obstacle data structures supporting efficient spatial queries, such as nearest-neighbor searches.

This interface abstracts different obstacle search algorithms using type erasure, allowing flexible integration of various implementations. Any obstacle search algorithm must conform to this interface to be used within the framework.

The following member functions must be implemented:

  • reinit(): Reinitializes the internal state. This should be called after obstacle positions have changed or the underlying triangulation has been modified.
  • get_obstacles_in_cell(): Identifies all obstacles that partially or fully occupy a given cell and stores their properties in a specified destination.
  • get_obstacles_in_cell_batch(): Identifies all obstacles that intersect with any cell in a given cell batch and stores their properties in a specified destination.

See below for more details.
