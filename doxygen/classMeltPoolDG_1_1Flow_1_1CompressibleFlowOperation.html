◆ set_subsonic_outflow_with_fixed_static_pressure()

template<int dim, typename number >
void MeltPoolDG::Flow::CompressibleFlowOperation< dim, number >::set_subsonic_outflow_with_fixed_static_pressure ( const std::map< types::boundary_id, std::shared_ptr< Function< dim > > > &  outflow_fixed_pressure_bc)

Set a subsonic outflow boundary condition for all boundary ids occurring in the given std::map and applies the corresponding function at this boundary. This corresponds to a Dirichlet boundary condition for the static pressure part of the energy. The dynamic part is added according to the locally present velocity values as it is proposed in Hartmann R. and Houston P., An Optimal Order Interior Penalty Discontinuous Galerkin Discretization of the Compressible Navier–Stokes Equations.

Parameters
outflow_fixed_pressure_bcMap of boundary ids and corresponding functions for the outflow boundaries.
Note
The function simply passes the parameters to the corresponding operator function.
