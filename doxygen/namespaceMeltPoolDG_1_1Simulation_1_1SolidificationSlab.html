class  SimulationSolidificationSlab
 

Detailed Description

This simulation represents a simple test example for heat transfer with solidification. "A pseudo one-dimensional slab (material properties of ice / water) with length L = 1m is subject to a fixed temperature Tˆ = 253K on its left edge at x = 0. The initial temperature in the whole slab is T0 = 283K." [1]
